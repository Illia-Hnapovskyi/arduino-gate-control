# Arduino Gate + Radar + Music + DHT11 + Joystick Game

Ця прошивка зберігає старий шлагбаум і додає:

- ультразвуковий радар;
- живу карту об’єктів у браузері;
- три мелодії через пасивний buzzer;
- одночасну роботу радара та музики;
- температуру й вологість із DHT11 на сайті;
- гру «Космічний захисник», якою керує джойстик;
- фонову 8-бітну музику через Passive Buzzer на D3;
- окремі ігрові ефекти через Active Buzzer на D5.

## Старі підключення — без змін

### Сервопривід SG90

- помаранчевий дріт → D9
- червоний дріт → 5V
- коричневий дріт → GND

### Датчик HC-SR04

- VCC → 5V
- TRIG → D7
- ECHO → D6
- GND → GND

## Додаємо два buzzer-и

### Passive Buzzer — музика

У наборі є два buzzer. Для музики потрібен саме **Passive Buzzer** — чорний
циліндр без білої наклейки.

- довга ніжка `+` → через резистор 100Ω до D3
- коротка ніжка `−` → GND

Active Buzzer не підходить для мелодій: він може відтворювати лише один
постійний звук.

### Active Buzzer — ефекти гри

Другий, **Active Buzzer**, відтворює короткі сигнали пострілу, влучання,
зіткнення, бонусів, боса, досягнення та завершення гри незалежно від музики:

- довга ніжка `+` → цифровий контакт **D5**;
- коротка ніжка `−` → **GND**.

Гучність ефектів регулюється повзунком на сайті через PWM. Якщо навіть
`0–20%` надто голосно, додай резистор 100Ω послідовно між D5 і довгою ніжкою
`+`. Перед зміною підключення обов’язково від’єднай USB.

## Додаємо датчик температури та вологості DHT11

У твоєму наборі це маленька **синя прямокутна решітка** на невеликій темній
платі з трьома штирями. Біля штирів можуть бути написи `S`, `+`, `−` або
`DATA`, `VCC`, `GND`.

Підключай за написами на платі, а не за кольорами дротів:

- `S`, `DATA` або `OUT` → цифровий контакт **D2** Arduino;
- `+` або `VCC` → **5V**;
- `−` або `GND` → **GND**.

Це готовий трьохконтактний модуль, тому додатковий резистор для нього не
потрібен. Прошивка читає його без окремої бібліотеки.

Якщо 5V і GND Arduino вже зайняті, використовуй бічні шини макетної плати:

1. Arduino `5V` → червона шина `+`.
2. Arduino `GND` → синя шина `−`.
3. `VCC/+` усіх модулів → червона шина.
4. `GND/−` усіх модулів → синя шина.

Усі контакти землі мають бути спільними. Не підключай DHT11 до `VIN` або 9V.

## Додаємо джойстик

У наборі це **маленька чорна квадратна плата з високою чорною ручкою**.
Ручку можна нахиляти ліворуч, праворуч, угору й униз. Якщо натиснути на неї
зверху, всередині спрацює кнопка. На краю модуля є п’ять контактів із
підписами.

Підключай за написами на модулі, а не за порядком контактів або кольорами
дротів:

- `VRx` → аналоговий контакт **A0** Arduino;
- `VRy` → аналоговий контакт **A1** Arduino;
- `SW` → цифровий контакт **D4** Arduino;
- `+5V`, `5V` або `VCC` → **5V**;
- `GND` → **GND**.

Додатковий резистор джойстику не потрібен. Прошивка вмикає внутрішній резистор
для контакту `SW`.

Якщо єдина пара `5V` і `GND` вже зайнята, підключи живлення джойстика до тих
самих шин макетної плати:

- `+5V/VCC` джойстика → червона шина `+`;
- `GND` джойстика → синя шина `−`.

Перед вставлянням будь-якого дроту **від’єднай USB**. Не рухай старі контакти
`D2`, `D3`, `D6`, `D7` і `D9`. Не підключай джойстик до `VIN` чи 9V.

У грі:

- нахил ручки керує рухом корабля;
- натискання ручки (`SW`) виконує постріл;
- Passive Buzzer на `D3` відтворює мелодію;
- Active Buzzer на `D5` відтворює ігрові ефекти.

Після запуску вкладки «Гра» відпусти джойстик і натисни на сайті
«Калібрувати центр». Це прибере повільний рух корабля, якщо механічний центр
ручки трохи відрізняється від 512.

## Ігровий Serial-протокол

Браузер надсилає ASCII-команди, завершені символом нового рядка, на швидкості
115200 baud. Буфер прошивки приймає не більше 40 символів до нового рядка. Усі
команди нижче коротші за цей ліміт; старі команди залишаються сумісними.

| Команда | Дія |
| --- | --- |
| `GAME:1`, `GAME:0` | Увійти в режим гри або повернутися до шлагбаума. |
| `GAME:PAUSE`, `GAME:RESUME` | Призупинити або продовжити гру й звук. |
| `GAME:OVER` | Завершити гру та відтворити старий сигнал `OVER`. |
| `GAME:SOUND:0\|1` | Вимкнути або ввімкнути всю ігрову музику й ефекти. |
| `SFX:VOLUME:n` | Гучність Active Buzzer у відсотках від 0 до 100. |
| `SFX:назва` | Відтворити короткий ефект із таблиці нижче. |
| `TRACK:START`, `TRACK:STOP` | Почати або зупинити браузерний музичний потік. |
| `TRACK:TONE:частота:мс` | Нота Passive Buzzer: 0–4000 Гц, 20–1000 мс. |

Підтримувані назви `SFX`:

| Назва | Подія |
| --- | --- |
| `SHOT` | Звичайний постріл. |
| `SCORE` | Знищена ціль і нараховані очки. |
| `CRASH` | Корабель отримав пошкодження. |
| `OVER` | Забіг завершено. |
| `POWER` | Підібрано підсилення. |
| `SHIELD` | Активовано щит. |
| `BOSS` | Поява або нова фаза боса. |
| `WARN` | Небезпечна хвиля чи атака. |
| `ACH` | Відкрито досягнення. |
| `LASER` | Постріл лазером. |
| `MISSILE` | Запуск ракети. |
| `EMP` | Електромагнітний імпульс. |
| `RECORD` | Установлено новий рекорд. |
| `LOW` | Попередження про низький запас життя. |
| `MENU` | Коротке підтвердження дії в ігровому меню. |

Active Buzzer має одну власну частоту, тому події розрізняються тривалістю та
серіями коротких імпульсів. Прошивка планує їх через `millis()` без довгих
`delay`, тож читання джойстика, Serial, шлагбаум і радар не блокуються. Музичні
ноти й надалі відтворює окремий Passive Buzzer на D3.

## Механічна частина радара

Електричні контакти не змінюються. Зніми картонну перекладину шлагбаума та
закріпи HC-SR04 на білому пластиковому важелі сервопривода. Датчик повинен
рухатися разом із валом SG90, а два сріблясті «ока» — дивитися вперед.

Не вмикай режим радара, якщо перекладина шлагбаума ще прикріплена: сервопривід
сканує від 15° до 165°, тому перекладина може вдаритися об предмети.

## Як запустити

1. Від’єднай USB перед додаванням деталей.
2. Перевір Passive Buzzer: `D3 → резистор 100Ω → +`, а `− → GND`.
3. Перевір Active Buzzer: довга ніжка `+ → D5`, коротка `− → GND`.
4. Перевір DHT11: `S → D2`, `+ → 5V`, `− → GND`.
5. Підключи джойстик: `VRx → A0`, `VRy → A1`, `SW → D4`,
   `+5V → 5V`, `GND → GND`.
6. Відкрий `arduino-smart-gate.ino` в Arduino IDE.
7. Вибери `Tools → Board → Arduino UNO`.
8. Вибери USB-порт плати.
9. Натисни Upload.
10. Після прошивки закрий Serial Monitor.
11. Відкрий вебпанель у Chrome або Edge.
12. Натисни «Під’єднати Arduino».
13. Відкрий вкладку «Гра».
14. Відпусти джойстик, натисни «Калібрувати центр», а потім «Почати гру».

Швидкість порту: **115200 baud**.

## Безпека

- Не подавай 9V на контакт 5V або безпосередньо на SG90.
- Не подавай 9V на DHT11.
- Не подавай 9V на джойстик.
- Не подавай 9V на жоден buzzer або цифровий контакт D3/D5.
- Завжди звіряй `S`, `+` і `−` на самому модулі: кольори кабелю можуть
  відрізнятися.
- Якщо плата перезапускається або SG90 тремтить, від’єднай USB.
- Для важчого механізму потрібне окреме стабільне живлення 5V зі спільним GND.
